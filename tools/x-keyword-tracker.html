X Keyword Tracker

What this helps with

  • Monitor up to 5 X.com keyword searches simultaneously
  • Stay on top of trending topics, brand mentions, or competitors
  • Set auto-refresh intervals so searches open at the right cadence

How it works

  • Each pane holds one keyword — type it in the pane header
  • Set a global refresh interval (default: 5 min) and click Apply
  • When the timer hits zero, the pane flashes and opens X.com search in a new tab
  • Use "Open All" to immediately open all keywords in new tabs
  • Pause/Resume controls let you stop all timers at once

Tips

  • Use X search operators like "phrase", from:handle, #hashtag, or lang:en
  • Add up to 5 panes — fewer panes means each occupies more width
  • Your keywords and interval are saved in this tab until you close it
