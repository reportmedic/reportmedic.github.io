Keyword Tracker — How it works

What you can do

  • Track up to 5 keywords in vertical panes — add or remove panes freely
  • Pick a different search engine per pane (DuckDuckGo, Google, X.com, etc.)
  • Set a global auto-refresh interval — each pane reloads on its own countdown
  • Pause/resume all timers globally, or control each pane individually
  • ↗ Open All instantly fires all searches in new tabs at once

Embed support by engine

Most search engines block iframe embedding via browser security headers. Engines marked ✓ Embeds show results directly in the pane. Others display a fallback with an "Open in new tab" button — the search still works.

Operator tips

  • X.com: from:handle, #hashtag, "exact phrase", lang:en
  • Google/DDG: site:example.com, filetype:pdf, intitle:keyword
  • Reddit: add site:reddit.com in a Google/DDG pane for deep dives
