There is no penalty for a wrong answer on this test, which changes everything about how you should behave in the final minute. Every blank is a guaranteed zero and every guess is worth a quarter of a point in expectation before any elimination. Eliminating even one option lifts that to a third. Never leave a question blank, and if the clock is running out, spend the last thirty seconds filling every remaining answer rather than solving one more.
