Outlier Finder

What this helps with

  • Detect spikes, drops, and unusual values
  • Find rows that break expected ranges
  • Spot data quality anomalies quickly
  • Prioritize where to investigate first

Common causes

  • Upstream load issues or partial refresh
  • Bad joins creating inflated counts
  • Unit/scale changes (%, dollars, decimals)

What to do next

  • Validate outliers against source system
  • Use Audit notes to record findings
  • Run Schema Validator if columns look wrong
  • If you need guidance, use Fix My Report
