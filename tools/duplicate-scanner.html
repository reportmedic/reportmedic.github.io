Duplicate File Scanner

What this helps with

  • Compare two folders and identify files in the target that already exist in the source
  • Choose from three comparison methods: SHA-256 content hash, name + size, or name only
  • Move detected duplicates into an organized _duplicates folder preserving directory structure
  • Generate a 3-column CSV log: source path, target path, and new duplicate path
  • Filter and search results by filename, extension, or minimum size

How it works

  • Select a source folder (X) — this is your reference / original
  • Select a target folder (Y) — duplicates in this folder will be found
  • Pick a comparison method and click "Scan for Duplicates"
  • Review the duplicate report — grouped by matching content
  • Optionally move duplicates in Y into Y/_duplicates/ preserving their subfolder structure
  • Export a complete move log as CSV with all three path columns

Example

  • Source: X/photos/3.txt matches Target: Y/backup/f1/1.txt
  • After move: Y/_duplicates/backup/f1/1.txt
  • Log row: X/photos/3.txt | Y/backup/f1/1.txt | Y/_duplicates/backup/f1/1.txt

Privacy

  • 100% local — no data is uploaded or sent anywhere, ever
  • Uses the File System Access API for direct folder operations
  • File contents are only read for hashing — never stored or transmitted
