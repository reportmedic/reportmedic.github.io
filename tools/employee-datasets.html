Employee Datasets

What this helps with

  • Realistic HR data for building dashboards, reports and analytics demos
  • Testing ETL pipelines, data-quality checks and BI tool configurations
  • Training and onboarding — practice analysis without touching production data
  • Cross-region comparison exercises with consistent schemas

What's included

  • 8 datasets — USA, India, EU (27 countries), UK (43 regions), Australia (8 states/territories), LATAM (20 countries), Africa (54 countries), China (34 provinces)
  • 40,000+ records each — evenly distributed across every country/state/territory within each region
  • 30 columns per file — employee ID, name, DOB, gender, emails, phone, address, hire date, status, type, department, title, manager, location type, salary, performance, plus 10 company-level fields
  • Region-appropriate names, phone formats, postal codes, salary ranges and company naming conventions

Schema overview

  • Identity: employee_id, full_name, preferred_name, date_of_birth, gender_identity
  • Contact: work_email, personal_email, phone_number
  • Location: home_address_city, home_address_state, home_address_zip
  • Employment: hire_date, employment_status, employment_type, department, job_title, manager_employee_id, work_location_type
  • Compensation: salary_base_annual, performance_rating_latest
  • Company: company_id, company_legal_name, company_trade_name, company_hq_state, company_industry_naics_code, company_primary_operating_state, company_operating_states_list, company_operating_states_count, company_state_focus_flag, company_state_focus_notes

How to use

  • Browse by region chips or type a keyword in the search bar
  • Click Columns on any card to inspect the full 30-column schema
  • Hit Download CSV to grab an individual file, or use Download All to fetch every file

Privacy

  • 100% synthetic data — no real individuals
  • No tracking, no sign-ups — just data
  • Files are served directly from GitHub
