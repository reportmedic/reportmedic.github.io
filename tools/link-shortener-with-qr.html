What this helps with

  • Turn a long link into a shorter share link (optional)
  • Generate a QR code you can download as PNG

Good to know

  • Local mode creates a link like go.html#…. Anyone opening it will be redirected.
  • If you need a public shortener, run it server‑side (browser-to-shortener requests are often blocked by CORS).
