What a .pptx file is

What is a .pptx file, and why can a browser open it?

A .pptx file is the presentation format introduced with PowerPoint 2007. Inside, it is a ZIP package containing XML files that describe each slide's text, positions, shapes, and images, plus the media files themselves. Because that structure is documented and readable, software other than PowerPoint, including this browser-based viewer, can parse the package and draw the slides it describes.

What is the difference between .ppt and .pptx?

The two formats come from different eras of PowerPoint and are built differently, which affects file size, how easily other software can read them, and which viewer you should use. The viewer on this page is built for the modern .pptx format. A legacy .ppt file is not rendered by either viewer: save a .pptx copy first (PowerPoint, LibreOffice Impress or Google Slides can do it), and the sister PPT Viewer page explains the old format and that conversion in its FAQ.

Does this viewer open .ppsx, .potx, or .pptm files?

Those extensions belong to the same modern PowerPoint family: .ppsx is a slideshow, .potx is a template, and .pptm is a macro-enabled presentation. They are not in this viewer's listed formats, which are .pptx, plus .xlsx, .xlsm, and .docx. If you have one of these variants, open it in PowerPoint or a compatible editor and save a copy as .pptx, then view that copy here.

Are macros in a presentation a safety risk in this viewer?

No macro code is executed here. The viewer reads a presentation file in order to draw its slides; it does not run the macros, scripts, or embedded programs a file might contain. That is a general advantage of viewing rather than opening a file in a full editor, although you should still only accept presentation files from sources you trust.

Rendering

Will my slides look the same as they do in PowerPoint?

For most decks, very close. The viewer renders the core slide content from the file itself: positioned text, shapes, embedded images, and the original layout. Why does the text on my slides use a slightly different font?

Decks are usually written in Calibri, which many devices do not have installed. This viewer uses Carlito, a font with the same character widths as Calibri, so line breaks and text layout stay in the same places even without Calibri. If a deck uses a font with no available substitute, the browser falls back to a default font and the text may wrap differently.

Troubleshooting

Why won't my .pptx file open at all?

The usual causes are an incomplete download, which may leave a very small or 0 KB file, or a file that is not really a presentation, such as a PDF or ZIP file renamed to .pptx. Download the file again and check its size and type. A corrupted file can often be rescued by opening it in PowerPoint and using Open and Repair, then saving a fresh copy.

Can I open a password-protected .pptx file?

This viewer does not prompt for a password, so a password-protected or encrypted presentation cannot be opened here directly. If you are the owner, or have the owner's permission, open the file in PowerPoint, remove the password protection, and save an unprotected copy for viewing. Treat that copy with the same care as the original, since it no longer has that protection.

I selected my file, but the deck has not appeared yet. What should I do?

Give it a moment first. Because the deck is processed entirely in your browser, a large presentation, especially one with many high-resolution images, can take a little while to appear, and keeping the tab in the foreground while it loads helps. If nothing appears after a reasonable wait, reload the page and select the file again, or try a current desktop browser, which handles heavy decks more comfortably than a phone.

Why is a very large presentation slow to open?

Because everything happens in your browser, a very large deck, especially one with many high-resolution images, depends on your device's available memory and processing power. Closing other browser tabs frees memory, and a desktop browser on a computer generally handles heavy decks better than a phone. There is no server-side size cap; the limit is a practical one set by the device itself.

Alternatives

Is this a replacement for Microsoft PowerPoint Viewer?

For viewing and presenting, yes. Microsoft has retired its free PowerPoint Viewer application, so it is no longer a current option for opening a deck on a machine without PowerPoint. This viewer covers that role in the browser: it opens and presents .pptx files with nothing to install, no licence, and no account, on Windows, Mac, Linux, and ChromeOS alike.

How is this different from Google Slides or PowerPoint for the web?

Those services require you to upload your file to their servers and to sign in with a Google or Microsoft account, after which the file is stored in that account. This viewer requires neither: no upload, no sign-in, and nothing stored. If you need collaborative editing, the account-based services fit better; if you need private viewing or presenting, this page is the shorter route.

How is this different from installing LibreOffice or WPS Office?

Those are capable free office suites, and the right choice if you regularly need to edit presentations. The difference is commitment: they require downloading and installing software, keeping it updated, and having permission to install on the machine. This viewer installs nothing and needs no permission, which makes it the practical option for one-off viewing, borrowed computers, and locked-down devices.
