Jupyter Notebook Viewer

What this helps with

  • View Jupyter Notebook (.ipynb) files without installing Python or Jupyter
  • Render code cells with syntax highlighting, Markdown with headings and images, LaTeX math via KaTeX, and cell outputs including tables and plots
  • Quickly preview notebooks from colleagues, GitHub, or course materials

How it works

  • Upload a .ipynb file from your device, or paste a raw URL / GitHub Gist link
  • The notebook renders instantly in your browser using ipynb2html
  • Use Print / PDF to save a clean copy

Privacy

  • Your files stay on your device — nothing is uploaded to any server
  • URL-fetched notebooks are downloaded directly to your browser via a CORS proxy
