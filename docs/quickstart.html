Quickstart

  1. Create a GitHub account and a repo named USERNAME.github.io (or use an Organization).
  2. Upload this zip’s contents into that repo (root folder).
  3. Enable GitHub Pages: Settings → Pages → Deploy from branch (main / root).
  4. Open your site at https://USERNAME.github.io.

Tip: The homepage already links all 10 tools. Replace each /tools/*.html page with the real tool UI when ready.
