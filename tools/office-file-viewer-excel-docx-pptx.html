Office File Viewer FAQ

Can I open an XLSX file without Excel?

Yes. Drop the .xlsx file into this viewer, or use the file picker to select it, and the spreadsheet appears as a table in your browser. You do not need Microsoft Excel, Microsoft Office, or any spreadsheet program installed. Use the Sheet dropdown to move between worksheets. Nothing is uploaded, and the preview runs entirely on your own device.

Can I open a DOCX file without Word?

Yes. Drop the .docx file into this viewer, or select it with the file picker, and the document appears as a clean, readable preview in your browser. You do not need Microsoft Word or Microsoft Office installed. Headings, paragraphs, lists, images, and table contents are shown, so you can read and check the document on any device with a modern browser.

Can I open a PPTX file without PowerPoint?

Yes. Drop the .pptx file into this viewer, or select it with the file picker, and the presentation opens as a slide deck in your browser. You do not need Microsoft PowerPoint or Microsoft Office installed. Slides render with their positioned text, shapes, and images, and you can step through the deck or present it full screen using Present mode.

How do I open a file — drag and drop, or the file picker?

Either way works. Drag the file from your computer and drop it onto the viewer, or click the file picker and select it from your files. The viewer accepts one file at a time in .xlsx, .docx, or .pptx format, reads it in your browser, and shows the preview automatically. There is nothing to install and no settings to choose first.

Can I open more than one file at a time?

No. The viewer works with one file at a time, which keeps the preview clear and avoids mixing up documents. When you have finished with a file, use the Clear button to reset the viewer completely, then drop in or select the next .xlsx, .docx, or .pptx file. Each file is handled separately, and clearing removes the current preview before you start again.

Can I open an email attachment in XLSX, DOCX, or PPTX format?

Yes. Save the attachment to your device first, then drop it into this viewer or select it with the file picker. That works for spreadsheets, Word documents, and presentations sent by email, including files from people who use software you do not have. Because nothing is uploaded, you can preview attachments without handing them to a viewing server, before deciding whether to keep, forward, or reply to them.

Does this viewer work on a Mac, Chromebook, or phone?

Yes. The viewer runs in any modern web browser, so it works on Windows, Mac, Linux, and Chromebook computers, and on iPhone, iPad, and Android devices. There is no platform version to download and nothing to install. If the device can open this page and reach the file, whether it is stored locally or saved from an email, it can preview it.

Do I need a Microsoft 365 subscription or a Google account?

No. This viewer needs neither. There is no Microsoft 365 subscription, no Microsoft account, no Google account, and no sign-in of any kind. You also avoid the alternative those services usually require: uploading your file to their servers. Here you simply open the page, choose your .xlsx, .docx, or .pptx file, and read it in your browser, on your device.

Can I preview a file from a USB drive or my downloads folder?

Yes. The viewer opens files from wherever they sit on your device: a USB drive plugged into the computer, your downloads folder, or a folder you saved an email attachment into. Use the file picker to browse to that location and select the .xlsx, .docx, or .pptx file, or drag it onto the viewer if your system allows dragging from that window.

Excel files

How do I view the different sheets in a spreadsheet?

Use the Sheet dropdown. When an .xlsx file contains more than one worksheet, each sheet renders as its own table, and the dropdown lets you switch between them without reopening the file. This makes it practical to check a workbook sheet by sheet — for example, moving from a summary sheet to the detailed data behind it — all inside the same preview.

What happens if a sheet has more than 200 rows?

The preview shows the first 200 rows of each sheet. That is enough to check the structure, headings, and opening data of most spreadsheets, but it is a preview limit, not the whole file. If you need rows beyond 200, open the original file in a spreadsheet program such as Excel or Google Sheets, or split the spreadsheet into smaller files before previewing it here.

Can I check a spreadsheet's figures before a meeting?

Yes, that is one of its handiest uses. Open the .xlsx file a few minutes before the meeting and the figures are there in a readable table, sheet by sheet, with no Excel installation and no sign-in to arrange first. It works just as well on a phone or a borrowed laptop, and because nothing is uploaded, the numbers stay on your device while you check them.

Can I open an older .xls spreadsheet here?

No. The supported formats are exactly .xlsx, .docx, and .pptx, and the older .xls spreadsheet format is not on that list. To view an .xls file here, open it first in Excel, LibreOffice, or a similar program and save a copy as .xlsx, then drop the new file into the viewer. Your original .xls file stays unchanged throughout.

Can I open a CSV file in this viewer?

No. This viewer is for .xlsx, .docx, and .pptx files, and CSV is a different job. A CSV file is plain text data rather than an Office document, so use a dedicated CSV tool on ReportMedic instead, where the data can be previewed, cleaned, and analysed properly. If your spreadsheet is currently a CSV, saving it as .xlsx first also works here.

That makes it well suited to reading a report, letter, or draft on a device without Word. Can I read a Word document comfortably on a phone?

Open this page in your phone's browser, pick the .docx file from your downloads or files app, and read the document on the train, between meetings, or wherever you happen to be — no Word app, account, or upload involved at any point.

Can I open an older .doc document here?

No. The supported formats are exactly .xlsx, .docx, and .pptx, and the older .doc Word format is not on that list. To view a .doc file here, open it first in Word, LibreOffice, or a similar program and save a copy as .docx, then drop the new file into the viewer. Your original .doc file stays unchanged throughout.

PowerPoint files

How do I present a PPTX file with this viewer?

Open the .pptx file and click Present to run the deck full screen. Move through the slides with the arrow keys, the Space bar, or Page Up and Page Down, just as you would in a presentation program. Slides keep their positioned text, shapes, and images, so the deck reads as designed. Press the exit control when you have finished presenting.

Can I present from a computer at a client site?

Yes. Open this page in the browser on the client-site computer, load your .pptx file from a USB drive or your downloads, and click Present to run the deck full screen. Nothing needs installing and no account is needed, so there is nothing to ask their IT for first. When you finish, close the tab and the presentation leaves with you.

Nothing is sent to ReportMedic or to any third party, nothing is stored, and there is no server copy left behind. Closing the page clears the file from your browser's memory.

Open as many .xlsx, .docx, and .pptx files as you need, at whatever size your browser can handle. Editing and sharing

Can I edit a spreadsheet, document, or presentation in this viewer?

No. This is a viewer, not an editor, for all three formats. You can read, check, navigate, and present files, but you cannot change their contents here. That also means the viewer can never alter your work by accident: your original file is never changed in any way. To make edits, open the original file in Excel, Word, PowerPoint, or another editor.

How do I share a file I have viewed here?

Share the original file itself, in the usual way: attach it to an email, send it through your chat app, or share it from your cloud storage. The viewer creates no link and keeps no copy, because your file never left your device. Anyone receiving the file can preview it on this page themselves, free, without Microsoft Office or any account.

Which of the three formats should I send a colleague who has no Office?

Send whichever format the file already is — .xlsx, .docx, or .pptx — together with a link to this page. Your colleague does not need you to convert anything first: they open the page, drop in the file you sent, and preview it free in their browser, with no Microsoft Office, no account, and no upload. That works for spreadsheets, documents, and presentations alike.

Can I present a deck from this viewer on Zoom or Teams?

Yes. Open the .pptx file here, start your Zoom or Teams call, and share the browser window showing the viewer. Click Present for full screen, then move through the slides with the arrow keys, Space bar, or Page Up and Page Down. Your audience sees only the slides, and because nothing was uploaded, the deck itself never passes through the meeting platform.

Troubleshooting

Why won't my file open — could it be renamed or the wrong format?

Possibly. The viewer accepts .xlsx, .docx, and .pptx files, and it reads the actual file, not just its name. A file that was renamed to change its extension, saved in an older format such as .xls or .doc, or exported in a different format will not open. Save a fresh copy in the correct modern format and try that file instead.

What should I do if my file is corrupted?

This viewer cannot repair a damaged file, and a corrupted .xlsx, .docx, or .pptx file will usually fail to open here, just as it would elsewhere. Try opening the original in Excel, Word, PowerPoint, or LibreOffice, which sometimes recover part of a damaged file, then save a clean copy in the modern format. If you hold another copy or backup, preview that instead.

Can I open a password-protected Office file?

No. The viewer has no password prompt, so it cannot open a password-protected .xlsx, .docx, or .pptx file. Open the file first in Excel, Word, or PowerPoint and enter the password there. If you are allowed to share an unprotected copy, save one without the password and preview that copy here. Never send your password to any online viewing service.

Why is a very large file slow to open, or failing to load?

Everything runs in your browser, so the practical limit is your device's available memory rather than any server limit. A very large spreadsheet, document, or image-heavy presentation can load slowly or strain an older phone or laptop. Try a current desktop browser, close other heavy tabs, or split or simplify the file in its own program, then preview the smaller copy here.
