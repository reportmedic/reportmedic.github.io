Quick Pivot

What this helps with

  • Summarize data by key dimensions
  • Create quick totals and breakdowns
  • Validate aggregates match the report
  • Spot where totals diverge

Common causes

  • Totals mismatch but row-level looks fine
  • Need to isolate which group causes variance
  • Different grouping/filters across runs

What to do next

  • Pivot both versions the same way
  • Use Reconcile to quantify differences by key
  • Export the pivot summary for sharing
  • If you need guidance, use Fix My Report
