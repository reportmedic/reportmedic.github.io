Date & Timezone Drift Checker

What this helps with

  • Find day/hour shifts between two exports
  • Spot timezone conversion and truncation issues
  • Explain “totals moved to a different day/week” problems

Common causes

  • One export uses local time and the other uses UTC
  • Date is truncated before aggregation (midnight boundaries differ)
  • DST transitions introduce a ±1 hour surprise

What to do next

  • Verify the same timezone is used end-to-end
  • Re-run the report using explicit timezone settings
  • Use the “Top bucket differences” table to isolate impacted ranges
