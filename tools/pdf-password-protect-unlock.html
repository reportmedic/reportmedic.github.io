PDF Password Protect / Unlock

Add a password to a PDF, or remove a password if you know it.

Password types

  • User password: required to open the file
  • Owner password: optional admin password (can allow extra permissions)

Notes

  • If your PDF is already encrypted, you can unlock it by loading with the password and saving a new copy.
  • Some viewers interpret permissions differently; always test the result.
