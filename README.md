# ReportMedic — GitHub Pages Launch Pack

This repo is ready for GitHub Pages.

## Deploy
1. Create repo: `USERNAME.github.io`
2. Upload all files from this folder to repo root
3. GitHub: Settings → Pages → Deploy from branch → `main` / `(root)`
4. Visit: https://USERNAME.github.io

## Customize
- Edit `index.html` for homepage copy
- Update tool pages in `/tools/`
- Update policy pages in `/docs/`
- Styles: `/assets/css/styles.css`
