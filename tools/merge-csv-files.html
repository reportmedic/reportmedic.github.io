Merge CSV Files

What this solves

  • Merging huge CSV files (100MB, 500MB, even 1GB+) that crash Excel, Google Sheets, or other tools
  • Simple row append - File 1's data followed by File 2's data
  • Optionally skips the header row from File 2 to avoid duplicate headers

How it works

  • Select or drag-drop two CSV files
  • Click "Merge Files" to combine them
  • Files are streamed in chunks (not loaded entirely into memory)
  • Download the merged result as a single CSV

Privacy

  • Everything runs locally in your browser using the File API
  • No data is uploaded to any server
