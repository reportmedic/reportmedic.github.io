File Analyzer

Purpose: help data modellers quickly understand a dataset’s shape before building models, mappings, and transformations.

What you get

  • Column cards: unique counts plus quick type hints (numeric vs text)
  • Preview: scrollable table with sortable columns and configurable preview size
  • Filters: stack multiple rules (AND/OR) and instantly see the impact
  • Group by: summarize by any field and view a bar chart (Top N)
  • Pivot: rows × columns cross-tab with selectable aggregation
  • Local only: processing happens in your browser, files aren’t uploaded
