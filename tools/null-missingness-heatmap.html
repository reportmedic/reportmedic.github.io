Null & Missingness Heatmap

What this helps with

  • Find columns that silently stopped populating
  • Spot segments where missingness spikes (group-by)
  • Catch export/pipeline issues before you share a report

Common causes

  • Join keys changed, causing partial dropouts
  • Filters removed a segment (stores, regions, channels)
  • Date/time boundary issues (timezone/DST)

What to do next

  • Validate schema (required fields) first
  • Check duplicates on business keys if totals inflate
  • Use Reconciliation when totals drift
