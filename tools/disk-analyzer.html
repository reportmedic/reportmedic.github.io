Disk Space Analyzer

What this helps with

  • Find what's consuming disk space — folders, file types, large files
  • Drill into nested folders recursively with full path metrics
  • Visualize usage with an interactive treemap
  • Filter by extension, size range, date modified, category, or name
  • Export results to CSV for reporting or sharing

How it works

  • Click "Choose Folder" and select any local directory
  • The tool reads all files recursively in your browser
  • Metrics are computed: size, % of total, % of parent, last modified
  • Expand/collapse folders in the tree view, or switch to Treemap
  • Use filters to zero in on specific file types or size ranges
  • All columns are sortable; toggle visibility to customize your view

Privacy

  • 100% local — no data is uploaded or sent anywhere
  • Works offline after the page loads
  • File contents are never read — only names, sizes, and dates
