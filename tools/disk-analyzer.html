Disk Space Analyzer

What this helps with

  • Find what's consuming disk space — folders, file types, large files
  • Drill into nested folders recursively with full path metrics
  • Visualize storage with an interactive squarified treemap
  • Filter by extension, size range, date modified, category, or filename
  • Export results to CSV for reporting or audit trails

How it works

  • Click "Choose Folder" and select any local directory
  • All file sizes and dates are read recursively in your browser
  • Metrics computed: size, % of total, % of parent, last modified
  • Expand/collapse folders in tree view, or switch to Treemap
  • All columns are sortable; toggle visibility to customize the view
  • Double-click any folder row to expand all its children at once

Privacy

  • 100% local — no data is uploaded or sent anywhere, ever
  • Works offline after the page loads
  • File contents are never read — only names, sizes, and dates
