Text Compare

Best for

  • Comparing report exports, logs, config files, SQL, or documentation
  • Spotting what changed without scanning manually
  • Producing a quick “what changed” summary for teammates

How highlights work

  • Green (right): lines added in the updated version
  • Red (left): lines removed from the original version
  • Blank rows: inserted only to keep both sides aligned

Helpful options

  • Ignore spaces/case when exports differ only by formatting
  • Ignore empty lines to reduce noise
  • Show differences only when you want a short review list
