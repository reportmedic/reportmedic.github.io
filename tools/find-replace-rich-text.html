Find & Replace (Rich Text)

What this solves

  • Most find-and-replace tools strip formatting, forcing you to reformat after
  • This tool preserves bold, italic, underline, colors, links, lists, and all rich text formatting
  • Paste from Word, Google Docs, Outlook, or any rich text source

How to use

  • Paste your formatted text into the editor
  • Type your search term and replacement
  • Use Replace (one at a time) or Replace All (all at once)
  • Copy the result as rich text to paste back into your document

Options

  • Match case: only find exact case matches
  • Whole word: only match complete words, not partial matches
  • Regex: use regular expressions for advanced pattern matching (e.g. \d+ for numbers)

Line breaks

  • Remove all: strips every line break for a single continuous block
  • Remove (keep paragraphs): removes single line breaks but preserves paragraph spacing

Privacy

  • Everything runs locally in your browser
  • No text is uploaded or stored on any server
