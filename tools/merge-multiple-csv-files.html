Merge Multiple CSV Files

What this solves

  • Merging any number of huge CSV files that crash Excel or Google Sheets
  • Simple row append: File 1 rows, then File 2 rows, then File 3, etc.
  • Header row is kept from the first file; skipped from all others by default

How to use

  • Drop all your CSV files at once, or browse and add more
  • Drag to reorder files in the queue
  • Click "Merge All Files" to combine them
  • Download the merged output as a single CSV

Privacy

  • Everything runs locally using the File API and streaming chunks
  • No data is uploaded to any server
